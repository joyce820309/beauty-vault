# BeautyVault Export 文件需求

## 概述

使用者需要從現有資料中快速輸出純文字文件，方便查看手上已擁有的物品。
Export 內容須**自動過濾已丟棄（disposed）的品項**。

## 三大分區

### 一、膚況區
匯出膚質背景資料（手動維護於個人檔案 / Profile）：
- 膚質總體描述
- 季節變化
- 鼻翼問題
- 眼周暗沉類型
- 膚色設定
- AI 角色設定（用於 AI 推薦時的 prompt 前綴）

### 二、彩妝品區（item_type = 'makeup'）
依 category / subcategory 分組列出，格式：
```
【{category}】
{subcategory}（若有）
  品牌 【產品名稱】 ＃色號
```

目前 category 包含（但不限於）：
- 粉底、妝前乳、防曬、遮瑕
- 眼影、眼線/臥蠶、眉毛
- 腮紅、唇彩
- 定妝、修容類

### 三、保養品區（item_type = 'skincare'）
依 category / subcategory 分組列出，格式：
```
【{category}】
  品牌 【產品名稱】
```

目前 category 包含（但不限於）：
- 化妝水、精華液、乳液/乳霜
- 眼霜、面膜/泥膜
- 保濕棒/油類

## Export 頁面功能規劃（/my/export）

### 選擇範圍
使用者可以選擇：

1. **分區 Export**
   - 膚況區
   - 彩妝品 > 各分類（見彩妝品分類匯出對照表）
   - 保養品 > 各分類（保養品分類匯出對照表，美容工具不是從`品項`拿資料，而是從`Tool`表撈）

2. **大範圍 Export**
   - 所有彩妝品 (彩妝品分類匯出對照表的所有內容)
   - 所有保養品 (保養品分類匯出對照表的所有內容)

3. **Export All**
   - 輸出完整文件（包含三大分區）

## Export All 輸出範例

```
***推薦產品前，須確認為2026年仍在售且台灣可購買。***
***所有建議需誠實中立，不鼓勵衝動購買或高風險產品。***


【角色設定】
請以專業敏弱乾肌保養顧問角度，推薦保養與彩妝。

【我已擁有的彩妝品】
（依類別自動從資料庫匯出，過濾已丟棄品項）

【我已擁有的保養品】
（依類別自動從資料庫匯出，過濾已丟棄品項）
```
